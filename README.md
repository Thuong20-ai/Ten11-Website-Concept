# TEN11 Website Concept

Bản concept giao diện website e-commerce cho TEN11.

- Một file HTML duy nhất (`index.html`), không cần build.
- Mở trực tiếp `index.html` bằng trình duyệt để xem.

## Đăng lên GitHub Pages
1. Tạo repo mới và upload toàn bộ nội dung thư mục này.
2. Vào **Settings → Pages**, chọn Branch `main` và thư mục `/ (root)`, bấm Save.
3. Sau ít phút web sẽ chạy tại `https://<username>.github.io/<tên-repo>/`.
